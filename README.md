PROJECT:  PHẦN MỀM QUẢN LÝ SÁCH THƯ VIỆN

Giới thiệu cấu trúc chương trình:
  Tên đề tài: Phần mềm quản lý sách thư viện
  Ngôn ngữ lập trình: Java.
	Công cụ phát triển: Android Studio.
	Cơ sở dữ liệu: SQLite.
	Giao diện: XML.

Các chức năng của app: 
	Thêm sách mới. 
	Cập nhật thông tin sách
	Xóa sách 
	Hiển thị tất cả Sách trong thư viện cá nhân. 
	Tìm kiếm sách theo tên hoặc tác giả nhập từ màn hình.
	Lọc danh sách theo thể loại hoặc trạng thái
	Thoát chương trình
